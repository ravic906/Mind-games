# Constellations

A calm, satisfying memory game set in the night sky. Watch the stars light up, then trace them in the same order. Each constellation is longer and faster than the last.

**Play:** open `index.html` in any browser (desktop or phone). No build step and no dependencies.

- Every level is a real constellation (Orion's Belt, Cassiopeia, the Big Dipper, Scorpius and more) drawn from real star positions, with star names that appear as you trace them
- Lifetime badges at 5, 15, 30, 50, 75, 100, 150 and 250 constellations: Stargazer, Space Explorer, Milky Way Enthusiast, Constellation Hunter, Nebula Navigator, Galactic Voyager, Star Cartographer, Keeper of the Cosmos
- Pentatonic notes on every star, so each run plays a melody
- Shields forgive mistakes, perfect rounds build a ×5 multiplier, golden stars pay extra
- Finished constellations stay in the sky; the ambient score layers up with your streak

`constellations.html` is the same game without the document wrapper (used for publishing as a Claude artifact).
